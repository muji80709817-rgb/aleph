# 케셰브 릴리스·재현 기록 (22단계)

이 문서는 학생이 작성한 **재현 기록이자 학생 진술**입니다. 서버(ALEPH)의 AI는 이 문서를 원문과 대조해 읽을 뿐이며, 서버가 새 환경에서 명령을 실행했다는 뜻이 아닙니다. 22단계 통과는 원문 검토 기준의 수료이고, 실제 운영 인증이나 v1.0 인증이 아닙니다.

각 결과에는 어떻게 확인했는지 적었습니다.

| 표기 | 뜻 |
|---|---|
| **실행 확인** | 이 PC에서 명령·화면을 실제로 실행해 관찰함 |
| **실제 화면** | 브라우저(Claude 데스크톱 앱 내장 브라우저)에서 페이지를 열어 관찰함 |
| **예제(demo)** | `-Demo` 예제 엔진으로 관찰함. 실제 연결이 아님 |
| **모의 확인** | 가짜 DOM·가짜 입력으로 학생 함수만 따로 실행함 |
| **코드 확인** | 코드만 읽음 |
| **미확인** | 확인하지 못함 |
